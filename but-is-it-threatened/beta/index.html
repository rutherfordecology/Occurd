Building the name list

Step 1 — Load everything from NZOR. NZOR is used first because it has the most complete collection of names — scientific names, synonyms, old combinations, and vernacular names with their links to scientific names.

Step 2 — Add common and Māori names from NZTCS, and let NZTCS win any disputes. Some Māori and common names appear in NZTCS but not in NZOR, so these are added to fill gaps. Where NZOR and NZTCS disagree about which species a name belongs to, NZTCS wins. For example, NZOR records "tōtara" as a name for Leucopogon fraseri (pātōtara), while NZTCS correctly links it to Podocarpus totara. NZTCS is treated as more authoritative for New Zealand species names, so the NZOR entry is replaced.

How a name is matched when you search

Step 1 — Exact match. The search term is looked up in the name list exactly as typed (lowercased, macrons kept). This covers most searches — Rattus rattus, kererū, Clianthus puniceus.

Step 2 — Match with macrons stripped. If nothing is found, the search tries again ignoring macrons. This means typing "kereru" still finds "kererū", and "totara" still finds "tōtara". Without this step, anyone without a macron keyboard would get no results for many NZ names.

If neither step finds anything, the name is unmatched.

How the threat status is found

Once a species has been identified, the tool resolves it to an NZTCS taxon through a sequence of passes, weakest last, each one refusing to guess rather than picking a winner. The first to find a unique answer wins.

Exact and canonical. The name is looked up as an NZTCS key (which carry authorities and synonyms) and as the accepted name inside one. This covers the majority of species — Rattus rattus, Nestor notabilis, Tradescantia fluminensis.

Variant. The same lookup retried with rank markers dropped, and with quotes and macrons folded — sources disagree about whether to write "subsp." at all, and about whether Woodworthia "Kaikōura" keeps its macron or its closing quote.

Authority prefix. Authorities can't be stripped by rule — they sit inside a name, as in Pimelea aridula Cheeseman subsp. aridula — so instead every 2-to-n-word leading prefix of every NZTCS name is indexed, and kept only where every entry sharing that prefix agrees on one accepted name. Apteryx haastii finds Apteryx maxima this way — the authority is on the end, but it's still a genus transfer NZOR itself has no synonym link for.

Nominate subspecies, not most threatened — and never hiding a difference. A bare binomial that NZTCS only assesses at infraspecific rank takes the nominate — the subspecies repeating the specific epithet — never whichever subspecies happens to be most threatened, but only when that can't change the answer. Where NZTCS's subspecies under that binomial differ in status, a selected region decides if it can (see "Region override" below); otherwise you're shown every subspecies and asked. Acanthisitta chloris with no region shows both the Declining North Island rifleman and the Not Threatened South Island rifleman, rather than quietly reading Not Threatened.

Subsequence. Catches an authority sitting further inside the name, e.g. Pimelea aridula subsp. aridula found inside Pimelea aridula Cheeseman subsp. aridula. Only used when the written name's words appear in order within exactly one NZTCS entry.

One-letter correction. A single-character spelling difference — insertion, deletion, substitution, or transposition — accepted only when exactly one NZTCS name is that close. Recovers typos like Charmichaelia australis for Carmichaelia and Meuhlenbeckia for Muehlenbeckia.

Latin gender. Epithet endings folded (-us/-a/-um and similar), genus left alone — Anthosachne apricus finds Anthosachne aprica. Unique matches only.

Region override. Wherever the passes above would otherwise settle for the nominate, or find no unique subspecies at all, a selected region gets checked first against a hand-curated table of where each subspecies actually occurs. None of NZTCS's subspecies can be there — you're warned rather than given an answer. Exactly one can — used silently. Several can, but they all carry the same status — the nominate is used silently, since the choice couldn't have changed the answer. Several can and their statuses differ — you're asked, but only among the ones actually possible in that region, not every subspecies NZTCS lists nationally. Falco novaeseelandiae (the NZ falcon) resolves silently to a different subspecies, with a different status, in Gisborne, North Canterbury, and Southland — three regions, three answers, no question asked in any of them.

Show all subspecies. With no region selected, or once the region has said its piece and a genuine question remains, the tool falls back to showing every subspecies NZTCS lists under that species, highlighting the most threatened. This is the last resort, not the default, and is flagged as a guess rather than a determination.

Parent species. A trinomial that resolves to nothing, whose binomial does resolve, drops to the binomial — but only where NZTCS lists no other taxon under it. Paryphanta busbyi busbyi resolves to Paryphanta busbyi; where a subspecies has instead been elevated to its own species — Oligosoma nigriplantare polychroma is really O. polychroma, not a Chatham Island skink dressed differently — that's a taxonomic act no string rule can see, and is corrected by hand instead.

A genus written on its own — Woodworthia, Carex — never inherits a species' status through any of these passes: the record is real, but there's nothing to attach a status to.

Names shared by more than one species

When loading, the tool checks every common name and Māori name to see how many different species use it. If two or more species share a name, it is flagged as ambiguous. This is common in NZ — tītī refers to several petrel and shearwater species, puka is used for both Griselinia lucida and Meryta sinclairii, and mingimingi applies to several shrub species across Coprosma, Leucopogon, and others. When a name is ambiguous, all the species that share it are listed rather than guessing.

NVS 6-letter codes

The tool also accepts NVS (National Vegetation Survey) codes — the 6-letter shorthand used by ecologists in the field, typically the first 3 letters of the genus and first 3 of the species (e.g. PODTOT for Podocarpus totara, LEPSCO for Leptospermum scoparium). There are 8,259 codes loaded from the NVS Databank. Old or synonym codes are recognised and redirected to the current preferred name. NVS codes work in both the search box and batch lookup.

Remaining limitations

Native/exotic is only available when online. Whether a species is native or exotic comes from the NZOR website in real time. In batch mode this is not fetched, so most batch results show "Unknown" for origin. Species flagged as introduced or naturalised in NZTCS, or listed on the NPPA, will still show as Exotic.

Pick a region to narrow subspecies. Selecting a region checks it against the region table, but only for the 63 taxa currently in it; most NZTCS subspecies splits aren't in it yet. For anything not covered, or with no region selected, the tool uses the nominate only where every subspecies shares its status, and otherwise shows every option with the most threatened highlighted, so the uncertainty is never hidden.
